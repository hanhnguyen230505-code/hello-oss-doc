- # hello-oss-doc

- Một chương trình C nhỏ in ra dòng chữ "Hello OSS", dùng để thực hành
- viết tài liệu và chọn giấy phép cho dự án mã nguồn mở.

- ## Mục tiêu

- - Làm quen với cách tổ chức một repository mã nguồn mở trên GitHub.
- - Thực hành viết README, CONTRIBUTING và chọn LICENSE.
- - Là dự án mẫu để luyện quy trình Issue, Pull Request.

- ## Yêu cầu

- - Trình biên dịch GCC (hoặc Clang)
- - Git

- ## Hướng dẫn build và chạy

- ```bash
- gcc main.c -o hello
- ./hello
- ```

- Kết quả mong đợi:

- ```
- Hello OSS
- ```
